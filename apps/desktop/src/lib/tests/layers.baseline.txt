# file and fails on a violation it does not list, and on a line here that no longer occurs.
#

# address (an existing cycle running through a new home is still that cycle). One line per
# violation, sorted, as `from -> to : kind`, where kind is upward, cycle, deep, import, literal or route;
# the test's header says what each means.
