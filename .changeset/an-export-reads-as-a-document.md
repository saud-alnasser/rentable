an exported file now reads as a document rather than as the table behind it. money, counts and dates arrive as figures a spreadsheet can total, sort and filter — they used to arrive as text rendered through the interface's own locale, which no spreadsheet could add up. headings are written for a file, a units file names the complex holding them and a payment statement names its contract and its tenant, a contract's paid and expected amounts are two columns instead of one fraction, and a file narrowed by a search or a filter says so in its name rather than silently replacing the last one
