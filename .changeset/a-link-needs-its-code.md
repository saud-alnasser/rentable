an owner whose every machine is gone gets back in with their turso account. after the consent, an account that already holds an organization is no longer refused: the walk says so in a sentence, asks for the owner's username and password, and connects this machine to what is already there, signed in, with every credential in the organization renewed on the way. only the owner's password does it, and while a machine an owner or an administrator is on has been seen in the last week the walk says so instead and points at the link that machine can make
