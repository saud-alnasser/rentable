the connect screen takes either link in one field: an organization link records the organization on this machine and lands on the sign-in, and an invitation link records it, names the organization and your username, and asks you to choose the password you will sign in with from then on. a link that has lapsed or was withdrawn says to ask whoever invited you for a new one, a link for another organization says to disconnect this machine first, and a link that was already opened says so and offers the sign-in, since a second machine is connected by the same link and the password you chose is what opens it. the sign-in screen of a connected machine now offers the connect screen too, for a reset link
