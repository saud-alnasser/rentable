the account section lists every machine signed in as you, by the name its system gives it, with when it was last seen and when it was added, this machine first. each other machine can be signed out on its own row, or all of them at once below the list; both ask first and name the machines, and your password stays the same. offline, the sign-out reaches the machine once this one is back online. a machine that has not run this version yet cannot be signed out on its own, and says so; signing out all other machines reaches it.
